# Инструкция для владельца: управление сайтом IV&AX MOTO

**Обновлено:** 2026-11-07

Эта инструкция — для работы в админке сайта без программирования: каталог, цены, заявки, отзывы, сотрудники.
Названия кнопок и разделов приведены так, как они написаны в админке.

## 1. Вход в админку

1. Откройте в браузере адрес вида `https://ivax-moto.ru/<секретный-путь>/`. Секретный путь (`ADMIN_PATH`) задаёт
   администратор сервера — спросите у него и **никому не сообщайте**: стандартного адреса `/admin/` у сайта нет.
2. Введите логин и пароль. Пароль — не короче 12 символов, не похожий на логин и не из простых.
3. После **5 неудачных попыток** вход для этого логина с этого компьютера блокируется на **15 минут**. Если
   заблокировали сотрудника, суперпользователь может снять блокировку: раздел «Axes» → «Попытки доступа» →
   удалить запись с его логином.
4. Сессия длится 12 часов. Закончив работу на чужом или общем компьютере, нажмите «Выйти» вверху справа.

На главной странице админки разделы:

| Раздел | Что внутри |
|--------|------------|
| **Каталог** | Электромотоциклы, Опции (справочник), Цвета, Настройки сайта |
| **Курс валют** | Курсы валют — история курса ЦБ РФ |
| **Заявки** | Заявки и Уведомления (очередь) |
| **Отзывы** | Отзывы покупателей |
| **Пользователи и группы** | Учётные записи сотрудников и их права |
| **Axes** | Журнал попыток входа (блокировки) |

## 2. Как добавить новую модель

### Шаг 1. Проверьте справочники
- **Опции.** «Каталог» → «Опции (справочник)». Если нужной опции нет, нажмите «Добавить»: **Код** — латиница
  в нижнем регистре, цифры и `_` (например `heated_grips`; потом не меняйте), **Название** — как на сайте,
  **Пояснение** — по желанию. Один раз созданную опцию можно использовать у любых моделей.
- **Цвета.** «Каталог» → «Цвета» → «Добавить»: код (латиница), название («Красный»), цвет в формате `#RRGGBB`.

### Шаг 2. Создайте модель
«Каталог» → «Электромотоциклы» → «Добавить электромотоцикл».

**Основное**
- **Название модели** — например `HY-M`. **Адрес страницы (slug)** заполнится сам (`hy-m`); допускаются только
  латинские буквы, цифры и дефисы. У опубликованной модели адрес **не меняйте** — сломаются ссылки и позиции в поиске.
- **Линейка** (`M`, `MX`), **Тип** (Спорт / Нейкед / Круизер / Туринг) — по ним работают фильтры каталога.
- **Опубликована** — пока заполняете, оставьте **без галочки**. **Популярная** — показывать на главной.
  **Порядок** — чем меньше число, тем выше модель в списке.
- **Короткое описание** — одна фраза для карточки. **Описание** — абзацы разделяйте пустой строкой.
  **Особенности** — по одной на строку.
- **Доступные цвета** — перенесите нужные в правый список. Если не выбрать ни одного, на сайте будут предложены все цвета.

Пишите только проверенные факты из документов поставщика. Не упоминайте бренд производителя и поставщика,
не пишите «под заказ», «лучший», «№1», сроки и гарантии, которых нет в договоре.

**Характеристики (по умолчанию для всех вариантов)** — мощность (в ваттах: 5 кВт = `5000`), привод, охлаждение,
напряжение, скорость, запас хода, тормоза, подвеска, шины.

**Служебное** (свёрнуто) — страна производства и «Внутренний код поставщика». На сайте не показываются.

### Шаг 3. Варианты (мощность / АКБ)
В блоке «Варианты» нажмите «Добавить ещё один…» для каждой комплектации:
- **Название варианта** — например `72 В · 100 А·ч` (уникальное внутри модели);
- **Ёмкость АКБ, А·ч** — обязательно;
- остальные характеристики заполняйте, только если они отличаются от модели (пусто — как у модели);
- **Цена поставщика, $** — из прайса в долларах. Пусто — на сайте будет «цена по запросу».

Колонка **«Цена на сайте»** покажет рублёвую цену после сохранения.

### Шаг 4. Опции модели
В блоке «Опции модели» добавьте строки:
- **Опция** — выберите из справочника (можно начать вводить название);
- **Статус** — «За доплату» и **Цена, $**, либо «Входит в комплектацию» (цена не нужна, на сайте — «в комплектации»).
Если выбрать «За доплату» и не указать цену, админка покажет ошибку.

### Шаг 5. Фото
В блоке «Фото» добавьте снимки: **файл** JPEG, PNG или WebP до 10 МБ; **Описание для поисковиков (alt)** —
обязательно, например «Электромотоцикл HY-M красный, вид сбоку»; **Порядок** — первое фото идёт на карточку.
Сайт сам уменьшит фото до 1800 px, переведёт в WebP и удалит из файла служебные данные (геометку, модель камеры).

Фото из прайса поставщика содержат его водяной знак — для рабочего сайта запросите у поставщика чистые фото.
Не загружайте фото с чужих сайтов и объявлений: на них есть авторские права.

### Шаг 6. Сохраните и опубликуйте
Нажмите «Сохранить». Проверьте цены в колонке «Цена на сайте», затем отметьте «Опубликована» и сохраните ещё раз.
Модель появится в каталоге и по адресу `/moto/<адрес-страницы>/`.

**Быстрый способ** для похожей модели: в списке отметьте существующую модель → действие
«Создать копию (неопубликованную)» → «Выполнить». Появится копия с вариантами, опциями и цветами (без фото);
поменяйте в ней название, адрес, цены и фото.

## 3. Публикация и снятие с публикации

- В списке «Электромотоциклы» поставьте или снимите галочку в колонке «Опубликована» и нажмите «Сохранить» внизу
  списка. Так же меняются «Популярная» и «Порядок».
- Или отметьте несколько моделей → действие «Опубликовать» / «Снять с публикации» → «Выполнить».
- Снятая модель пропадает из каталога, её страница перестаёт открываться. Заявки по ней сохраняются.
- **Не удаляйте** модели, которые продавались, — снимайте с публикации: так сохраняется история.

## 4. Цены, наценка, курс: «Настройки сайта»

«Каталог» → «Настройки сайта» → откройте единственную запись.

Цена на сайте считается так: **(цена варианта в $ + выбранные опции в $) × курс доллара ЦБ РФ + наценка**,
итог округляется **вверх** до выбранного шага. Доставка в цену не входит.

| Поле | Что делает |
|------|------------|
| **Наценка, ₽** | Добавляется к цене каждого варианта (по умолчанию 100 000 ₽) |
| **Округление цены вверх до, ₽** | 1, 10, 100, 500, 1 000 (по умолчанию) или 5 000 ₽ |
| **Курс доллара** | «Автоматически по курсу ЦБ РФ» (обычный режим) или «Вручную» |
| **Ручной курс, ₽ за $** | Используется только в режиме «Вручную» |
| **Курс сейчас** | Какой курс сейчас в расчёте, откуда и на какую дату. Надпись «УСТАРЕЛ» — курс старше 3 дней, сообщите администратору |

Нажмите «Сохранить» — цены на сайте пересчитаются сразу. Ручной курс — временная мера: не забудьте вернуть
«Автоматически», иначе цены перестанут следовать за курсом ЦБ.

В этой же записи — **контакты и реквизиты** (телефон, e-mail, адрес, режим работы, наименование продавца, ИНН,
ОГРН) и **ссылки на соцсети**. Они выводятся в шапке, подвале, на странице «Контакты» и в документах.
Поля в квадратных скобках `[…]` — заглушки: замените их настоящими данными перед запуском.

## 5. Обновить курс сейчас

Курс обновляется сам каждые 3 часа. Чтобы обновить немедленно:
Нажмите «Обновить курс с ЦБ РФ» в списке курсов: кнопка работает и при пустой истории, доступна с правом
`rates.change_rate`. Либо используйте массовое действие:
1. «Курс валют» → «Курсы валют».
2. Отметьте галочкой **любую** строку списка (действия в админке работают только с выбранными строками).
3. В списке «Действие» выберите «Обновить курс с сайта ЦБ РФ сейчас» → «Выполнить».
4. Вверху появится «Курс обновлён: …» или причина ошибки.

Если список пуст (сайт только запущен) — попросите администратора выполнить `python manage.py update_rate`.
Строка с «Принят: нет» и комментарием «Скачок курса …» — защита от ошибочных данных: курс, изменившийся больше
чем на 20 %, принимается только если следующая проверка подтвердит его. До этого цены считаются по последнему
принятому курсу. Если нужно срочно — временно включите ручной курс (раздел 4).

## 6. Заявки

«Заявки» → «Заявки». Новые заявки — сверху. Справа фильтры по статусу, типу и дате, сверху — поиск по имени,
телефону, модели и комментарию.

**Статусы:** «Новая» → «В работе» → «Завершена»; также «Отменена» и «Спам» (так помечаются заявки, похожие на
автоматические, — по ним уведомления не отправляются; просматривайте их иногда, вдруг там живой клиент).
Статус можно поменять прямо в списке и нажать «Сохранить» внизу, или выбрать заявки → действие
«Отметить «В работе»» / «Отметить «Завершена»».

**Карточка заявки:** имя, телефон, способ связи, комментарий, модель, **конфигурация** (вариант, опции, цвет,
курс и наценка на момент заявки, цена, которую видел клиент), итоговая цена, время и версия согласия. Эти поля
только для чтения. Изменять можно **статус** и **«Заметку менеджера»**. Внизу — история уведомлений по заявке.
Пометка «Конфигурацию нужно уточнить» значит, что модель сняли с публикации или комплектация изменилась —
уточните у клиента.

**Выгрузка в CSV (Excel):** выберите заявки → «Выгрузить в CSV (Excel)». Действие видно только тем, у кого есть
право «Выгрузка заявок с персональными данными». Файл содержит имена и телефоны: не пересылайте его в мессенджерах
и по почте, удалите после использования.

**Обезличить по просьбе клиента:** если клиент просит удалить его данные (152-ФЗ), найдите его заявки поиском
по телефону → отметьте → «Обезличить (удалить персональные данные)» → «Выполнить». Имя, телефон, комментарий и
заметка удаляются, также стирается текст уведомлений; конфигурация и сумма остаются для статистики.
Сначала откроется страница со списком заявок: до нажатия «Подтвердить обезличивание» данные не меняются.
Действие доступно тем, у кого есть право удаления заявок. Не откладывайте: сроки ответа на такие запросы
установлены законом. Заявки старше 3 лет обезличиваются автоматически каждую ночь.

## 7. Уведомления о заявках (очередь)

Каждая заявка сначала сохраняется на сайте, затем отдельная служба отправляет уведомления в Telegram и на почту.
Если Telegram или почта недоступны, заявка не теряется — служба повторит отправку
(через 1 мин, 5 мин, 30 мин, 2 ч, 6 ч, 12 ч, 24 ч).

«Заявки» → «Уведомления (очередь)»:
- **Ожидает** — ждёт отправки или повторной попытки; **Отправляется** — в работе; **Отправлено** — доставлено;
  **Не доставлено** — 8 попыток не удались. Колонка «Последняя ошибка» показывает причину.
- Чтобы повторить вручную: отметьте строки → «Повторить отправку сейчас» → «Выполнить».
  Это только постановка в очередь: доставку выполняет служба отправки. Записи «Отправляется» и «Отправлено»
  не изменяются; счётчик показывает фактически перепланированные записи.
- Если появляются «Не доставлено» или «Ожидает» висит часами — сообщите администратору (бот, почта или служба
  отправки). Пока проблема не решена, смотрите новые заявки прямо в разделе «Заявки».

В Telegram по умолчанию приходят **модель, комплектация и цена без имени и телефона** клиента (серверы Telegram
за рубежом) и ссылка «Открыть заявку». Контакты клиента — в письме и в админке.

## 8. Отзывы: модерация

«Отзывы» → «Отзывы» → фильтр «Статус: На модерации». На сайте видны только отзывы со статусом «Опубликован».
1. Откройте отзыв и прочитайте его. Публикуйте настоящие отзывы покупателей — и хорошие, и критические, если
   они по делу. Отклоняйте рекламу, оскорбления, чужие персональные данные (телефоны, адреса), бессмыслицу.
2. Отметьте отзывы → «Опубликовать» или «Отклонить» → «Выполнить».
3. Отклонённые отзывы автоматически удаляются через 90 дней.

Статус также можно изменить в карточке отзыва. Время модерации фиксируется в обоих случаях;
исходный текст, автор, оценка, модель и согласия доступны только для чтения. Создание отзывов через админку
запрещено: настоящий покупатель отправляет отзыв через публичную форму с двумя согласиями.

Текст отзыва не переписывайте. **Никогда не пишите отзывы сами и не заказывайте их** — недостоверные отзывы
нарушают ст. 5 ФЗ «О рекламе». В демо-версии показаны образцы с подписью «Пример отзыва»; на рабочем сайте
образцов нет — блок наполнится по мере появления настоящих отзывов.

## 9. Excel: выгрузка и загрузка каталога

- **Скачать:** «Электромотоциклы» → кнопка «Скачать каталог в Excel» вверху справа (файл `ivax-catalog.xlsx`).
- **Загрузить:** кнопка «Импорт из Excel / CSV» → выберите файл → «Проверить файл» → просмотрите изменения →
  «Применить». До нажатия «Применить» ничего не меняется.
- Галочка «Обновить статус публикации из файла» по умолчанию снята: публикация не меняется, а новые модели из
  файла появятся неопубликованными.
- Удаляются только варианты, которых нет в файле, у моделей из файла; цвета и фото не трогаются.
- Правила заполнения колонок — в [import-format.md](import-format.md). Всегда начинайте с выгруженного файла.

## 10. Учётная запись менеджера с ограниченными правами

Менеджеру нужны только заявки и отзывы. Не давайте ему статус суперпользователя.

**Один раз создайте группу:**
1. «Пользователи и группы» → «Группы» → «Добавить группу».
2. Имя: `Менеджеры`.
3. В списке «Права» найдите и перенесите вправо:
   - `Заявки | Заявка | Can view Заявка` и `Заявки | Заявка | Can change Заявка`;
   - `Отзывы | Отзыв | Can view Отзыв` и `Отзывы | Отзыв | Can change Отзыв`.
4. «Сохранить».

**Создайте пользователя:**
1. «Пользователи» → «Добавить пользователя» → логин и пароль (не короче 12 символов) → «Сохранить».
2. На следующей странице: поставьте **«Статус персонала»** (без него вход в админку невозможен),
   **не ставьте** «Статус суперпользователя», в «Группы» добавьте `Менеджеры` → «Сохранить».

Менеджер сможет менять статус и заметку заявок и модерировать отзывы. Выгрузку CSV
(`Заявки | Заявка | Выгрузка заявок с персональными данными`) и обезличивание (`Can delete Заявка`) давайте
отдельно и только тем, кому это действительно нужно. Когда сотрудник уходит — снимите галочку «Активный»
у его учётной записи.

Для просмотра истории отправки дополнительно выдать `leads.view_outbox`, для перепланирования —
`leads.change_outbox`. Просмотр курсов — `rates.view_rate`, обновление с ЦБ — отдельно `rates.change_rate`.
История курса не редактируется и не удаляется, даже суперпользователем.

Редактору каталога нужны права на модель и её inline-записи (`Variant`, `MotorcycleOption`, `Photo`).
Для импорта нужны `add/change_motorcycle`, `add/change/delete_variant`, `add/change/delete_motorcycleoption`
и `view_optiondef`. Для Excel-экспорта — `view_motorcycle`, `view_variant`, `view_motorcycleoption`, `view_optiondef`.
Для копирования — те же права просмотра плюс `add_motorcycle`, `add_variant`, `add_motorcycleoption`.
Кнопки скрыты без соответствующих прав, прямые запросы также проверяются сервером. Право изменения главной
модели само по себе не разрешает массовое изменение связанных вариантов и опций.

Права на пользователей, группы, разрешения и Axes обычным менеджерам не выдавать. Эти разделы предназначены
для владельца: стандартные права Django на изменение пользователей позволяют менять их полномочия.

## Локальная тестовая админка (не для VPS)

Из корня проекта в PowerShell, после установки `requirements-dev.txt`:

```powershell
$env:DJANGO_SETTINGS_MODULE="config.settings.dev"
$env:DJANGO_DEBUG="true"
$env:DATA_DIR=Join-Path $PWD "data/admin-sandbox"
$env:MEDIA_ROOT=Join-Path $env:DATA_DIR "media"
$env:SHOW_SAMPLE_REVIEWS="false"
New-Item -ItemType Directory -Path $env:DATA_DIR -Force | Out-Null
.venv/Scripts/python.exe manage.py migrate --noinput
.venv/Scripts/python.exe manage.py seed_catalog
.venv/Scripts/python.exe manage.py create_local_admin
.venv/Scripts/python.exe manage.py runserver 127.0.0.1:8011 --noreload
```

`seed_catalog` нужен только при первом создании этой песочницы. Команда администратора показывает
сгенерированный пароль один раз и отказывается менять существующего пользователя. Логин по умолчанию
`local-admin`; для дополнительной тестовой записи — `--username <другой-логин>`. Пароль в документации не хранится.
Войти: `http://127.0.0.1:8011/manage-ivax/`, если локальный `ADMIN_PATH` не переопределён.
Не переносить эту базу на VPS. Для production — только интерактивный `createsuperuser` из инструкции деплоя.

## 11. Чего никогда не делать

- Не сообщать никому свой пароль и адрес админки; не заводить общий логин на несколько человек.
- Не давать сотрудникам статус суперпользователя.
- Не публиковать выдуманные отзывы, «лучший/№1», несуществующие гарантии, сроки и скидки.
- Не указывать на сайте бренд производителя, контакты поставщика и формулировку «под заказ».
- Не загружать чужие фото и тексты; не выдавать фото поставщика с водяным знаком за свои.
- Не менять адрес страницы (slug) у опубликованной модели и коды опций в справочнике.
- Не пересылать выгрузки заявок в мессенджерах и не хранить их на личных устройствах.
- Не просить включить передачу имени и телефона в Telegram без консультации с юристом (трансграничная передача ПДн).
- Не менять юридические документы на сайте самостоятельно — только через разработчика по согласованию с юристом.
- Не открывать сайт для поисковиков (снятие `noindex`), пока не готовы домен, реквизиты и документы, — это делает
  администратор по вашему решению.
