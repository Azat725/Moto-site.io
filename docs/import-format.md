# Формат таблицы импорта каталога (Excel / CSV)

**Обновлено:** 2026-11-07 · **Код:** `apps/catalog/spreadsheet.py` (колонки, чтение файла), `apps/catalog/catalog_io.py`
(проверка значений, сравнение, применение), `apps/catalog/admin_import.py` (страница админки)

Импорт нужен, чтобы обновить много моделей и цен за раз — например, когда пришёл новый прайс поставщика.
Самый надёжный способ: скачать текущий каталог кнопкой **«Скачать каталог в Excel»** (файл `ivax-catalog.xlsx`
уже в нужном формате), исправить его и загрузить обратно.

## 1. Как устроен файл

- **Одна строка = один вариант модели** (мощность / батарея). У модели с четырьмя вариантами — четыре строки.
- Строки одной модели объединяются по колонке `slug`. Поля модели (название, описание, характеристики, опции)
  берутся из **первой** строки модели; в остальных строках их можно повторить или оставить пустыми.
- Форматы: `.xlsx` (лист «Каталог», а если его нет — первый лист) или `.csv` (UTF-8, в том числе с BOM, либо
  Windows-1251; разделитель `;` или `,` определяется по первой строке).
- Ограничения: файл до 5 МБ, до 2000 строк, распакованный `.xlsx` — до 50 МБ. Пустые строки пропускаются.

### Заголовки: соглашение `Название [ключ]`

Программа читает из заголовка **ключ в квадратных скобках в конце**: `Модель [name]` → `name`. Текст перед скобками
можно писать как удобно. Если скобок нет, ключом считается весь текст заголовка (без учёта регистра), то есть
заголовок можно написать просто `name`. Колонки с неизвестными ключами игнорируются. Порядок колонок не важен.

## 2. Колонки модели (`MODEL_COLUMNS`)

> **Важно.** Поля `name`, `line`, `type`, `sort`, `short`, `description`, `features` записываются в базу **всегда**:
> если колонки нет или ячейка пустая, значение станет пустым (`type` — «спорт», `sort` — 100). Поэтому не удаляйте
> эти колонки из выгруженного файла. Пустые **характеристики** (таблица ниже), наоборот, ничего не меняют.

| Ключ | Заголовок при выгрузке | Значение |
|------|------------------------|----------|
| `slug` | Адрес страницы | **Обязательно.** Латиница в нижнем регистре, цифры и дефисы, до 60 символов (`hy-m`). Это адрес `/moto/hy-m/` и ключ, по которому модель находится в базе. Не меняйте у существующих моделей — получится новая модель |
| `name` | Модель | **Обязательно.** Название, до 60 символов |
| `line` | Линейка | Например `M` или `MX` (используется в фильтре каталога) |
| `type` | Тип | `спорт`, `нейкед`, `круизер`, `туринг` (или `sport`, `naked`, `cruiser`, `touring`). Пусто — `спорт` |
| `published` | Опубликована | `да` / `нет` (также понимаются `1`, `yes`, `true`, `+`, `y`; всё остальное — «нет»). Применяется, только если при загрузке отмечено «Обновить статус публикации из файла» |
| `popular` | Популярная | `да` / `нет` — показывать в блоке популярных на главной. Применяется по той же галочке |
| `sort` | Порядок | Целое число, меньше — выше в списке. Пусто — 100 |
| `short` | Коротко | Короткое описание для карточки (до 200 символов) |
| `description` | Описание | Полный текст. Абзацы разделяйте пустой строкой (в ячейке Excel — дважды Alt+Enter) |
| `features` | Особенности (через ;) | Список через точку с запятой: `ABS; TFT-дисплей; Зарядка Type 2` |

Характеристики модели (общие для всех вариантов; заголовок при выгрузке совпадает с ключом).
**Пустая ячейка — значение не меняется** (у новой модели берётся значение по умолчанию).

| Ключ | Что это | Тип |
|------|---------|-----|
| `motor_power_w` | Мощность мотора, Вт | целое (`5000`) |
| `motor_layout` | Расположение мотора | текст (`Центральный`) |
| `drive` | Привод | `цепь` / `ремень` (или `chain` / `belt`) |
| `cooling` | Охлаждение | `воздушное` / `жидкостное` (также `водяное`; или `air` / `liquid`) |
| `voltage_v` | Напряжение АКБ, В | целое |
| `battery_type` | Тип АКБ | текст |
| `top_speed_kmh` | Максимальная скорость, км/ч | целое |
| `range_min_km` / `range_max_km` | Запас хода от / до, км | целое |
| `brakes` | Тормоза | текст |
| `suspension_front` / `suspension_rear` | Передняя / задняя подвеска | текст |
| `tyre_front` / `tyre_rear` | Передняя / задняя шина | текст (`110/70-17`) |
| `tyre_kind` | Шины | текст (`Бескамерные`) |

## 3. Колонки варианта (`VARIANT_COLUMNS`)

| Ключ | Заголовок при выгрузке | Значение |
|------|------------------------|----------|
| `variant_label` | Вариант | **Обязательно.** Название, уникальное внутри модели: `72 В · 100 А·ч`. По нему вариант находится в базе |
| `battery_ah` | АКБ, А·ч | **Обязательно.** Целое число |
| `variant_voltage_v` | Вариант: напряжение | целое; пусто — как у модели |
| `variant_motor_power_w` | Вариант: мощность, Вт | целое; пусто — как у модели |
| `variant_drive` | Вариант: привод | `цепь` / `ремень`; пусто — как у модели |
| `variant_top_speed_kmh` | Вариант: скорость | целое; пусто — как у модели |
| `variant_range_max_km` | Вариант: запас хода до | целое; пусто — как у модели |
| `variant_brakes` | Вариант: тормоза | текст; пусто — как у модели |
| `variant_tyre_rear` | Вариант: задняя шина | текст; пусто — как у модели |
| `price_usd` | Цена, $ | Цена поставщика в долларах. Пусто — на сайте «цена по запросу» |

## 4. Колонки опций `opt:<код>`

- Одна колонка на опцию. Ключ — `opt:` и код опции из справочника: `Опция: ABS [opt:abs]`.
- **Код должен уже существовать** в админке в разделе «Опции (справочник)». Неизвестный код — ошибка, файл не принимается.
  Новую опцию сначала добавьте в справочник, затем в таблицу.
- Значение в ячейке (берётся из первой строки модели):
  - **число** — опция за доплату, цена в долларах (`223` или `223,50`);
  - **`включено`** (также `входит`, `вкл`, `да`, `included`) — входит в комплектацию, бесплатно;
  - **пусто**, `-` или `нет` — у модели этой опции нет. Если она была — она **будет удалена** у этой модели.

## 5. Значения: числа и текст

- Числа можно писать с пробелами, запятой или знаком доллара: `2 285`, `2285,00`, `$2285`. Отрицательные цены не принимаются.
- В целочисленных полях дробная часть отбрасывается.
- Текст при выгрузке получает явный строковый тип Excel: `=`, `+`, `@` не выполняются как формулы,
  исходный текст сохраняется без добавления апострофа и корректно проходит обратный импорт.

## 6. Как проходит импорт

1. Админка → «Электромотоциклы» → кнопка **«Импорт из Excel / CSV»** (нужны права на модели, варианты и опции;
   полный список — в [admin-guide.md](admin-guide.md#10-учётная-запись-менеджера-с-ограниченными-правами)).
2. Выберите файл. Галочка **«Обновить статус публикации из файла»** по умолчанию снята: тогда колонки
   «Опубликована» и «Популярная» игнорируются, а **новые модели создаются неопубликованными**.
3. Нажмите **«Проверить файл»**. Если есть ошибка (нет slug, неизвестная опция, не число в цене, нет ёмкости АКБ
   и т. п.), появится сообщение «Файл не принят: …» с номером строки или моделью — **в базе ничего не меняется**.
4. Если ошибок нет, появится **предпросмотр**: для каждой модели — «Новая модель», «Будет обновлена» (со списком
   изменений: какие поля, «варианты/цены изменены», «опции изменены») или «Без изменений». Отдельно перечислены
   модели, которые есть на сайте, но отсутствуют в файле, — они **не изменятся**.
5. Нажмите **«Применить»**. Все изменения записываются одной транзакцией: либо всё, либо ничего.
   Применяются данные, показанные в предпросмотре (файл повторно не читается). «Отмена» — ничего не меняет.

## 7. Что импорт меняет, а что нет

| Объект | Поведение |
|--------|-----------|
| Модели из файла | создаются или обновляются по `slug` |
| Название, линейка, тип, порядок, тексты модели | перезаписываются значениями из файла (пустое → пустое) |
| Характеристики модели | меняются только заполненные ячейки |
| Модели, которых нет в файле | не меняются и **не удаляются** |
| Варианты модели из файла | обновляются по названию варианта; новые — добавляются |
| Варианты модели, которых нет в файле | **удаляются** (только у моделей, перечисленных в файле) |
| Опции модели | приводятся к файлу: опции с пустой ячейкой у этой модели удаляются |
| Цвета | **не трогаются** (в таблице нет колонки цветов — выбор цветов в админке сохраняется) |
| Фото | не трогаются |
| Статус публикации | меняется, только если отмечена галочка |
| Справочник опций, «Настройки сайта», курс | не меняются |

## 8. Пример (CSV, разделитель `;`)

```
Адрес страницы [slug];Модель [name];Тип [type];Вариант [variant_label];АКБ, А·ч [battery_ah];Цена, $ [price_usd];Опция: ABS [opt:abs];Опция: Камера [opt:camera]
hy-m;HY-M;спорт;72 В · 60 А·ч;60;2285;223;
hy-m;;;72 В · 100 А·ч;100;2328;;
```
Здесь у HY-M два варианта, ABS за 223 $, камеры нет (если была — удалится). Это минимальный файл для новой модели:
у **существующей** модели такой файл сотрёт линейку, описание, особенности и порядок (см. «Важно» в разделе 2),
поэтому для правок всегда берите полную выгрузку «Скачать каталог в Excel».
